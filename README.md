### For Users - Just Visit!

**No install needed! Just open the website and enjoy Pamela's World!**

</div>

<br>

<div align="center">

### 📲 Start Pamela On Telegram

</div>

    1. Tap Start on Telegram
    2. Press START
    3. Add @Pamela_cullen_bot to your group
    4. Type: /add @ChannelName
    5. Done! Relax! Pamela will ping you!

<br>

<div align="center">

### 👩‍💻 For Developers - Run Locally

</div>

    git clone https://github.com/YOUR-USERNAME/pamelas-world.git
    cd pamelas-world
    python -m http.server 8000

Then open http://localhost:8000
